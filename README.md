# 🔐 Random Password Generator

**Автор:** Рихтер Андрей Ильич

## 📝 Описание

Мощное и удобное GUI-приложение для генерации случайных паролей с широкими возможностями настройки. Приложение позволяет создавать пароли различной сложности, сохранять историю генерации и быстро копировать пароли в буфер обмена.

## ✨ Возможности

- **Гибкая настройка паролей:**
  - Ползунок длины пароля (4-50 символов)
  - Выбор типов символов: цифры, буквы, спецсимволы
  - Визуальное отображение текущих настроек

- **История паролей:**
  - Автоматическое сохранение всех сгенерированных паролей
  - Отображение даты и параметров генерации
  - Сохранение истории в JSON файл
  - Очистка истории по требованию

- **Удобство использования:**
  - Копирование пароля в буфер обмена одним кликом
  - Интуитивно понятный интерфейс
  - Цветовая индикация действий
  - Валидация ввода с информативными сообщениями
